# Counter App

A simple Counter web application built using HTML, CSS, and JavaScript.

## Features

- Increase counter by 1  
- Decrease counter by 1  
- Increase counter by 10  
- Decrease counter by 10  
- Reset counter to 0  

## Tech Used

- HTML
- CSS
- JavaScript (Vanilla)

## How It Works

The app starts with a value of 0.  
JavaScript stores this value in a variable called `count`.

Each button calls a function:

- `increase()` adds 1  
- `decrease()` subtracts 1  
- `increase10()` adds 10  
- `decrease10()` subtracts 10  
- `reset()` sets the value back to 0  

After every change, the updated value is shown on the screen using `textContent`.

## Project Structure

- `index.html` – page layout and buttons  
- `counter.js` – counter logic and DOM manipulation
